# 기존 doulzzang 홈페이지용 동반 수정

이 폴더는 기존 홈페이지 프로젝트에 적용하는 파일입니다. 독립 웹서버 전체 소스가 아닙니다.

- `public/agv/control.html`: 객체 드롭, 미션 변화량 표시, 객체/공간 용도 전송
- `lib/isaac/assets.ts`: 용도를 검증하고 운영 PC에 `asset_import.kind`로 전달

기존 홈페이지의 같은 상대 경로에 반영하고 홈페이지 프로젝트에서 `npm run build` 검증 후 게시해야 실제 홈페이지에 적용됩니다. 운영 PC에서 ZIP만 설치하는 것으로 홈페이지 서버는 갱신되지 않습니다.

- `lib/isaac/relay.ts`: 공간 초기화·저장 안 함 명령 허용 목록. 기존 접속·조작권 검사를 그대로 사용합니다.
